Reusable Inventory System

A modular inventory module built for reuse across future titles.

What's Included

  • Grid-based inventory with stacking, drag-and-drop, and stack merging.
  • Category filters, name search, and slot sorting.
  • Tooltips and context menu for item details.
  • Equipment system and hotbar support.
  • JSON-based save and load.
  • 3D demo with pickups, consumables, equipment, and character stats.

How to Run in the Unity Editor

  1. Open the project in Unity 6 (saved with 6000.3.9f1).
  2. Open the scene: Assets/Scenes/Demo.unity.
  3. Press Play.

Add a New Item

  1. Create → Inventory → Item Data / Equipment / Consumable.
  2. Name the asset and fill the Inspector fields.
  3. Pick a model under Assets/Art/Items/Models and create a GameObject.
  4. Adjust transform so it sits correctly on the ground.
  5. Add ItemPickup and assign the ScriptableObject.
  6. Add Collider + Rigidbody (freeze rotation).
  7. Make a prefab under Assets/Prefabs.
  8. Assign the prefab to the ScriptableObject's World Prefab.
  9. Add the asset to ItemDatabase.
  10. Add the prefab to DemoItemSpawner.
